# 🏝️ Bajang Travel Lombok

### Website Resmi Bajang Travel — Explore Lombok, Indonesia

Selamat datang di repository resmi **Bajang Travel Lombok**.

Bajang Travel menyediakan layanan perjalanan wisata dan transportasi di Lombok, Nusa Tenggara Barat, Indonesia. Kami membantu wisatawan menikmati berbagai destinasi menarik di Lombok dengan pilihan paket wisata, transportasi, dan layanan perjalanan yang fleksibel.

---

## 🌴 Tentang Bajang Travel

**Bajang Travel** adalah layanan perjalanan wisata yang berbasis di Lombok dan melayani berbagai kebutuhan perjalanan wisatawan.

Kami menyediakan:

- 🏝️ Paket wisata Lombok
- 🤿 Paket 3 Gili & snorkeling
- ⛰️ Wisata Sembalun
- 🏖️ Wisata Pink Beach
- 🚗 Rental mobil
- 🚐 Transportasi wisata
- ✈️ Antar-jemput Bandara Internasional Lombok
- 📋 Itinerary perjalanan
- 💬 Konsultasi dan pemesanan melalui WhatsApp
